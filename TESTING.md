# Проверка

Запуск проверок логики: `node tests/verify.cjs` (Node.js требуется только для проверок, сама игра работает без него).

Проверены данные 15 карт, безопасное появление, одновременное движение, разные прыжки, способности, все виды плит, условия всех ворот и выходов, сбор предметов, расчёт звёзд, три смерти и поражение, восстановление на контрольной точке, переноска обычных/тяжёлых/совместных объектов, сфера и контур, теневой барьер, лифт, перенос персонажа движущейся платформой, последовательное открытие уровней, сохранение и восстановление после повреждённого JSON.

В проверках ворот и выходов необходимые условия устанавливаются напрямую для проверки логики. Эти проверки не являются полным игровым прохождением всех 15 карт. Первый уровень дополнительно пройден симуляцией обычного клавиатурного движения без принудительного открытия ворот.
